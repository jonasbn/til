# Visual config editor for Ghostty

[Ghostty Settings - Visual Config](https://ventz.github.io/ghostty-settings-visual-config/) is a browser-based editor
for Ghostty's configuration. Instead of hand-editing the plain-text config file, you tick options and tweak values in
a form, and it generates the config syntax for you — handy for exploring options you didn't know existed.

## Get your current config

To bring your existing settings into the editor (or just to see what you've changed from the defaults), dump them
from the terminal:

```bash
ghostty +show-config
```

This only prints the options that differ from the default. To see every available option with its documentation,
useful for discovering what else the visual editor exposes:

```bash
ghostty +show-config --default --docs
```

## Where the config file lives

The default location is:

```text
~/.config/ghostty/config
```

On macOS, Ghostty also accepts `~/Library/Application Support/com.mitchellh.ghostty/config`; whichever of the two
is non-empty is the one actually used. `ghostty +edit-config` opens the correct one directly in `$VISUAL`/`$EDITOR`
without you having to figure out which path is active.

## Reload after changes

Ghostty does **not** reload the config automatically when the file changes, whether you edited it by hand or pasted
in something generated by the visual editor. Reload it with:

- the default keybind: `Cmd+Shift+,` (macOS) or `Ctrl+Shift+,` (Linux/Windows), bound to the `reload_config` action
- the application menu
- or just restart Ghostty

See [Use Ghostty](use_ghostty.md) for the full default keybind table, including this one.
